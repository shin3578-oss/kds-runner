# kds-runner

患者情報を含まない自動化を動かすための**実行係**のリポジトリです。

## なぜ分けているか

GitHub Actions の無料枠（月2,000分）は**非公開リポジトリの実行時間だけ**を消費します。
公開リポジトリの実行は無料です。

本体の自動化は非公開リポジトリに置いてありますが、その中には
「患者情報にまったく触れない仕事」も混ざっています。それをここへ移すことで、
無料枠を本当に必要なもの（患者情報を扱う自動化）に残せます。

## つくり

- **このリポジトリにスクリプトは置きません。** 実行のたびに非公開リポジトリを
  `app/` に取り出して動かします。処理の中身は非公開のままです。
- 公開されるのは「どれをいつ動かすか」という段取りと、**マスク済みの実行ログ**だけです。
- すべての出力は `mask.py` を通します。カルテ番号・氏名・電話番号・メールアドレスは
  ログに出る前に伏せられます。
- 起動は手動（`workflow_dispatch`）のみ。時刻の管理は外部のスケジューラから行います。

## 置いてよい仕事の条件

1. 実行ログに患者を特定できる情報が出ないこと（移す前に過去のログを実際に走査して確認する）
2. `mask.py` を通すこと
3. 失敗したら必ず通知が飛ぶこと
